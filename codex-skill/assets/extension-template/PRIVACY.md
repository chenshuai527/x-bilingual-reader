# 英汉同步阅读隐私说明

更新日期：2026-09-09

## 单一用途

本扩展在用户主动启用后，将 X/Twitter 页面中的英文文字翻译为简体中文，同时保留英文原文。用户还可以主动开启当前标签页的视频语音识别与双语字幕、收藏英汉语句并导出 Word 文档。

## 处理的数据

- DeepSeek API Key：由用户自行提供，保存在当前 Chrome 的扩展本地存储中；浏览器重启或扩展更新后继续保留，直到用户主动清除、清除扩展数据或卸载扩展。
- Groq API Key：由用户自行提供，以相同方式保存在扩展本地存储中，用于视频语音识别。
- 网页文字：仅在用户启用英汉同步后，将需要翻译的文字发送到 DeepSeek 官方 API。
- 标签页音频：只有用户点击“开始视频翻译”后，扩展才捕获当前 X 标签页的声音，并把约 6 秒的音频片段发送到 Groq 官方 API；点击停止或标签页关闭后停止捕获。
- 视频字幕文本：Groq 返回的英文识别结果会发送到 DeepSeek 官方 API 翻译为中文。
- 本地收藏：英文、中文、来源网址、页面标题和收藏时间保存在 `chrome.storage.local`，用于本地查看和导出 Word。
- 设置状态：是否启用英汉同步保存在扩展本地存储中。

## 数据共享

扩展只把待翻译文字发送至 `https://api.deepseek.com`，把用户主动捕获的音频片段发送至 `https://api.groq.com`。相应 API Key 仅发送到对应的官方服务。扩展开发者不接收、存储或出售 API Key、网页文字、音频、浏览记录或收藏内容。

## 数据安全

- 与 DeepSeek、Groq 的通信均使用 HTTPS。
- API Key 不写入扩展代码、同步存储或开发者服务器，也不会同步到其他设备。
- API Key 仅由本扩展后台读取并用于请求 DeepSeek；网页本身不能读取扩展存储。
- API 返回内容只作为文字插入页面，不作为代码执行。

## 用户控制

用户可以在扩展设置页随时断开连接并清除浏览器中保存的 Key，也可以清空本地收藏。卸载扩展或清除扩展数据会删除 Key 和本地收藏；卸载前请先导出需要保留的 Word 文档。

DeepSeek、Groq 对其收到的数据分别适用各自的服务条款和隐私政策。Chrome 网上应用店上架时，应将本说明发布到一个公开 HTTPS 网页并在商店隐私页面填写一致的数据披露。
