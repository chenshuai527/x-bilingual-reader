# 英汉同步阅读使用说明

当前版本：`0.6.0`

## 能做什么

- 保留 X/Twitter 的英文原文，在下方显示简体中文。
- 用户在插件设置页提供自己的 DeepSeek API Key；无需安装 Node.js或运行本地代理。
- DeepSeek 暂不可用时，尝试使用 Chrome 本地 Translator API。
- 划选一句英文后点击“收藏这句”，收藏保存在当前 Chrome 的本地扩展存储中。
- 点击右下角面板的“导出 Word”，生成包含英文、中文、来源和收藏时间的 `.docx`。
- 当前不处理视频字幕和图片中的文字。

## 第一次连接 DeepSeek

1. 在 DeepSeek 开放平台创建新的完整 API Key，并确认 API 账户有可用余额。
2. 点击浏览器工具栏中的“英汉同步阅读”图标，或点击页面右下角的“设置 DeepSeek Key”。
3. 在设置页粘贴完整 Key，点击“验证并用于本次会话”。
4. 显示“已连接”后返回 X，点击“启用英汉同步”。

Key 只保存在当前 Chrome 会话内存中，不写入磁盘或同步存储。完全重启 Chrome、重新加载/更新/停用扩展后，需要重新输入一次；不需要每个网页重复输入。

隐私提示：启用 DeepSeek 后，待翻译的网页文字会通过 HTTPS 发送到 DeepSeek 官方 API，并产生用户自己的 API 用量。扩展开发者不接收 Key、网页文字或收藏内容。详细说明见 `PRIVACY.md`。

## 加载或更新扩展

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 如果还没加载，点击“加载已解压的扩展程序”，选择 `F:\创想\x-bilingual-reader`。
4. 如果已经加载，点击扩展卡片上的“重新加载”按钮，不必删除重装。
5. 确认扩展卡片显示 `v0.6.0`。
6. 点击扩展图标完成 DeepSeek 设置，然后打开或刷新 `https://x.com/`。

Edge 可以在 `edge://extensions` 加载。DeepSeek 主翻译直接调用官方 HTTPS API；Chrome 本地备用是否可用取决于浏览器版本。

## 收藏并导出 Word

1. 用鼠标划选想收藏的英文句子。
2. 点击选区附近出现的“收藏这句”。
3. 右下角会显示“已收藏 N 句”。
4. 点击“导出 Word”，浏览器会下载 `英汉语句收藏-日期.docx`。
5. “清空收藏”不可撤销，扩展会先弹窗确认。

收藏上限为 500 条。卸载扩展或清除扩展数据可能删除本地收藏，重要内容请及时导出 Word。

## 验收

- 扩展卡片和面板标题显示 `v0.6.0`。
- 设置页验证 Key 后显示“已连接”。
- 页面面板显示“DeepSeek V4 Flash 主翻译”。
- 英文原文仍然可见，中文出现在对应内容下方。
- 向下滚动后，新帖子自动翻译，同一条内容不会重复插入译文。
- 划选英文可以收藏，刷新 X 后收藏数量仍然存在。
- 下载的 `.docx` 能被 Microsoft Word 正常打开。
- Chrome 完全重启后 Key 自动清除，收藏内容仍保留。

## 调试

- 未配置 Key：点击“设置 DeepSeek Key”，创建并粘贴新的完整 Key。
- Key 无效：不要复制带 `*****` 的脱敏值；撤销旧 Key 后需重新连接。
- DeepSeek 余额不足或限流：设置页和页面译文位置会显示对应提示。
- Chrome 本地备用不可用：检查 Chrome 版本和 Translator API 支持情况。
- 扩展报错：在 `chrome://extensions` 的扩展卡片中打开 Service Worker 检查视图，或在 X 页面开发者工具 Console 查看详细信息。

## Chrome 网上应用店发布

上传以 `manifest.json` 为 ZIP 根目录的发布包。公开上架前，将 `PRIVACY.md` 发布到公开 HTTPS 网页，并在商店隐私页面如实披露网页文字会发送给 DeepSeek。
